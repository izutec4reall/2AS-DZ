# 📚 سلسلة التمارين الشاملة: حساب النهايات والمستقيمات المقاربة

> تدريبات مكثفة على إزالة حالات عدم التعيين الأربعة ($\frac{0}{0}, \frac{\infty}{\infty}, 0 \times \infty, +\infty - \infty$) وتعيين المقاربات الأفقية، العمودية، والمائلة، ودراسة الأوضاع النسبية.

---

## 📝 الجزء الأول: نص التمارين

### 🟢 التمرين 1 (إزالة حالات عدم التعيين بطرق منوعة)
احسب النهايات التالية مبيناً الطريقة المعتمدة:
1. $\lim_{x \to 3} \dfrac{x^2 - 2x - 3}{x^2 - 9}$
2. $\lim_{x \to +\infty} \left(\sqrt{x^2 + 3x} - x\right)$
3. $\lim_{x \to -\infty} \left(\sqrt{x^2 + 1} + x\right)$
4. $\lim_{x \to 0} \dfrac{\sqrt{1 + x} - \sqrt{1 - x}}{x}$
5. $\lim_{x \to +\infty} \dfrac{2x^3 - 4x + 1}{5x^3 + 7x^2 - 3}$

---

### 🟡 التمرين 2 (دراسة المقارب المائل والوضع النسبي)
لتكن الدالة $f$ المعرفة على $\mathbb{R} \setminus \{-1\}$ بـ:
$$f(x) = \dfrac{2x^2 + 5x + 1}{x + 1}$$
1. احسب نهايات الدالة $f$ عند $-\infty$ و $+\infty$ وعند $x = -1$ بقيم كبرى وصغرى.
2. أوجد الأعداد الحقيقية $a$ و $b$ و $c$ بحيث يكون: $f(x) = ax + b + \dfrac{c}{x + 1}$.
3. أثبت أن المستقيم $(\Delta)$ ذا المعادلة $y = 2x + 3$ هو مستقيم مقارب مائل لـ $(C_f)$ عند $\pm\infty$.
4. ادرس الوضع النسبي للمنحنى $(C_f)$ بالنسبة للمستقيم $(\Delta)$.

---

## 💡 الجزء الثاني: الحلول المفصلة خطوة بخطوة

### حل التمرين 1:
1. **$\lim_{x \to 3} \dfrac{x^2 - 2x - 3}{x^2 - 9}$:**
   * التعويض: $\dfrac{0}{0}$ (ح.ع.ت).
   * التحليل: البسط $(x - 3)(x + 1)$ والمقام $(x - 3)(x + 3)$.
   * الاختزال بـ $(x - 3)$:
     $$\lim_{x \to 3} \dfrac{x + 1}{x + 3} = \dfrac{3 + 1}{3 + 3} = \dfrac{4}{6} = \mathbf{\dfrac{2}{3}}$$

2. **$\lim_{x \to +\infty} (\sqrt{x^2 + 3x} - x)$:**
   * التعويض: $+\infty - \infty$ (ح.ع.ت).
   * الضرب بالمرافق:
     $$\dfrac{(\sqrt{x^2 + 3x} - x)(\sqrt{x^2 + 3x} + x)}{\sqrt{x^2 + 3x} + x} = \dfrac{(x^2 + 3x) - x^2}{\sqrt{x^2 + 3x} + x} = \dfrac{3x}{\sqrt{x^2(1 + 3/x)} + x}$$
   * بما أن $x > 0 \implies \sqrt{x^2} = x$:
     $$\dfrac{3x}{x(\sqrt{1 + 3/x} + 1)} = \dfrac{3}{\sqrt{1 + 3/x} + 1}$$
   * النهاية لما $x \to +\infty$: $\dfrac{3}{\sqrt{1} + 1} = \mathbf{\dfrac{3}{2}}$.

3. **$\lim_{x \to -\infty} (\sqrt{x^2 + 1} + x)$:**
   * التعويض: $+\infty - \infty$ (ح.ع.ت).
   * الضرب بالمرافق:
     $$\dfrac{(\sqrt{x^2 + 1} + x)(\sqrt{x^2 + 1} - x)}{\sqrt{x^2 + 1} - x} = \dfrac{(x^2 + 1) - x^2}{\sqrt{x^2 + 1} - x} = \dfrac{1}{\sqrt{x^2 + 1} - x}$$
   * لما $x \to -\infty$: $\sqrt{x^2 + 1} \to +\infty$ و $-x \to +\infty \implies$ المقام يؤول إلى $+\infty$.
   * إذن: $\lim_{x \to -\infty} \dfrac{1}{+\infty} = \mathbf{0}$.

4. **$\lim_{x \to 0} \dfrac{\sqrt{1 + x} - \sqrt{1 - x}}{x}$:**
   * الضرب بالمرافق $(\sqrt{1 + x} + \sqrt{1 - x})$:
     $$\dfrac{(1 + x) - (1 - x)}{x(\sqrt{1 + x} + \sqrt{1 - x})} = \dfrac{2x}{x(\sqrt{1 + x} + \sqrt{1 - x})} = \dfrac{2}{\sqrt{1 + x} + \sqrt{1 - x}}$$
   * بالتعويض عند $x = 0$: $\dfrac{2}{1 + 1} = \mathbf{1}$.

5. **$\lim_{x \to +\infty} \dfrac{2x^3 - 4x + 1}{5x^3 + 7x^2 - 3}$:**
   * نهاية حاصل قسمة أكبر حدين: $\lim_{x \to +\infty} \dfrac{2x^3}{5x^3} = \mathbf{\dfrac{2}{5}}$.

---

### حل التمرين 2:
1. **النهايات:**
   * $\lim_{x \to \pm\infty} f(x) = \lim_{x \to \pm\infty} \dfrac{2x^2}{x} = \lim_{x \to \pm\infty} (2x) = \pm\infty$.
   * عند $x = -1$: البسط يؤول إلى $2(-1)^2 + 5(-1) + 1 = 2 - 5 + 1 = -2 < 0$.
     * $\lim_{x \to -1^-} f(x) = \dfrac{-2}{0^-} = \mathbf{+\infty}$.
     * $\lim_{x \to -1^+} f(x) = \dfrac{-2}{0^+} = \mathbf{-\infty}$.
     * المستقيم $x = -1$ هو مستقيم مقارب عمودي.

2. **تعيين $a, b, c$ بالقسمة الإقليدية:**
   بقسمة $2x^2 + 5x + 1$ على $x + 1$:
   * $(2x^2 + 5x) \div (x + 1) = 2x$ والباقي $3x + 1$.
   * $(3x + 1) \div (x + 1) = 3$ والباقي $-2$.
   * إذن: $\mathbf{f(x) = 2x + 3 - \dfrac{2}{x + 1}}$ ($a = 2, b = 3, c = -2$).

3. **إثبات المقارب المائل $(\Delta)$:**
   $$\lim_{x \to \pm\infty} [f(x) - (2x + 3)] = \lim_{x \to \pm\infty} \left(-\dfrac{2}{x + 1}\right) = 0$$
   * إذن $(\Delta): y = 2x + 3$ مقارب مائل بجوار $\pm\infty$.

4. **الوضع النسبي:**
   * إشارة الفرق هي إشارة $-\dfrac{2}{x + 1}$:
     * على $]-\infty, -1[$: $x + 1 < 0 \implies -\dfrac{2}{x + 1} > 0 \implies$ **$(C_f)$ يقع فوق $(\Delta)$**.
     * على $]-1, +\infty[$: $x + 1 > 0 \implies -\dfrac{2}{x + 1} < 0 \implies$ **$(C_f)$ يقع تحت $(\Delta)$**.
