# الدوال كثيرات الحدود

> **تعريف:**  
> كثير الحدود $P$ هو دالة معرفة على $\mathbb{R}$ عبارتها من الشكل:
> $$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$$
> حيث $n \in \mathbb{N}$ هو **درجة كثير الحدود** (بشرط $a_n \neq 0$)، والأعداد $a_0, a_1, \dots, a_n$ هي **المعاملات**.

---

## 1. جذر كثير حدود وتحليله

> **تعريف الجذر:**  
> نقول إن العدد الحقيقي $\alpha$ هو **جذر** (أو حل) لكثير الحدود $P(x)$ إذا وفقط إذا كان:
> $$P(\alpha) = 0$$

> **مبرهنة التحليل:**  
> $\alpha$ جذر لكثير الحدود $P(x)$ ذي الدرجة $n \ge 1$ إذا وفقط إذا وجد كثير حدود $Q(x)$ ذو الدرجة $n - 1$ بحيث:
> $$P(x) = (x - \alpha) Q(x)$$

---

## 2. طرق تحليل كثير حدود من الدرجة الثالثة (بمعرفة جذر $\alpha$)

لتحليل $P(x) = ax^3 + bx^2 + cx + d$ حيث $P(\alpha) = 0$، نبحث عن المعاملات $A, B, C$ في:
$$P(x) = (x - \alpha)(A x^2 + B x + C)$$

### الطريقة 1: المطابقة (Identification)
1. ننشر العبارة:
   $$(x - \alpha)(A x^2 + B x + C) = A x^3 + (B - \alpha A) x^2 + (C - \alpha B) x - \alpha C$$
2. نطابق معاملات القوى المتساوية مع $P(x)$ لحل جملة معادلات وإيجاد $A, B, C$.

### الطريقة 2: القسمة الإقليدية (Division Euclidienne)
نُجري القسمة الإقليدية لكثير الحدود $P(x)$ على ثنائي الحد $(x - \alpha)$، فيكون الباقي $R = 0$ وحاصل القسمة هو $Q(x) = Ax^2 + Bx + C$.

### الطريقة 3: خوارزمية هورنر (Tableau de Horner)
ننشئ جدول المعاملات ونسقط المعامل الأول، ثم نضرب في الجذر $\alpha$ ونجمع بالتتابع:
$$\begin{array}{c|c|c|c|c}
 & a & b & c & d \\
\alpha & \downarrow & \alpha A & \alpha B & \alpha C \\
\hline
 & A = a & B = b + \alpha A & C = c + \alpha B & 0
\end{array}$$

---

## 3. ثلاثي الحدود من الدرجة الثانية: $E(x) = ax^2 + bx + c \quad (a \neq 0)$

### أ. الشكل النموذجي (Forme canonique)
$$ax^2 + bx + c = a \left[ \left( x + \frac{b}{2a} \right)^2 - \frac{\Delta}{4a^2} \right]$$
حيث المميز:
$$\Delta = b^2 - 4ac$$

### ب. حلول المعادلة $ax^2 + bx + c = 0$ وإشارة العبارة وتحليلها

| المميز | عدد وطبيعة الحلول | التحليل إلى جداء عوامل | إشارة $ax^2 + bx + c$ |
| :---: | :--- | :--- | :--- |
| **$\Delta > 0$** | حلان متمايزان:<br>$x_1 = \dfrac{-b - \sqrt{\Delta}}{2a}$<br>$x_2 = \dfrac{-b + \sqrt{\Delta}}{2a}$ | $a(x - x_1)(x - x_2)$ | **خارج الحلين:** نفس إشارة $a$<br>**بين الحلين:** عكس إشارة $a$ |
| **$\Delta = 0$** | حل مضاعف:<br>$x_0 = -\dfrac{b}{2a}$ | $a(x - x_0)^2$ | من نفس إشارة $a$ لجميع قيم $x \neq x_0$ وتنعدم عند $x_0$ |
| **$\Delta < 0$** | لا توجد حلول حقيقية في $\mathbb{R}$ | لا يمكن تحليله في $\mathbb{R}$ | من نفس إشارة $a$ دوماً على كامل $\mathbb{R}$ |

---

## 4. مجموع وجداء الحلين (علاقات فييتا - Relations de Viète)

### أ. لمعادلة من الدرجة الثانية ($ax^2 + bx + c = 0$):
إذا كان للمعادلة حلان $x_1$ و $x_2$ (متمايزان أو مضاعف) فإن:
$$S = x_1 + x_2 = -\frac{b}{a}, \qquad P = x_1 \cdot x_2 = \frac{c}{a}$$
> **تطبيق إيجاد عددين بمعرفة المجموع والجداء:**  
> لإيجاد عددين علم مجموعهما $S$ وجداؤهما $P$، نحل المعادلة من الدرجة الثانية:
> $$X^2 - S X + P = 0$$

### ب. لكثير حدود من الدرجة الثالثة ($ax^3 + bx^2 + cx + d = 0$):
إذا كان للمعادلة 3 حلول $x_1, x_2, x_3$، فإن علاقات فييتا تُعطى بـ:
$$\begin{cases}
x_1 + x_2 + x_3 = -\dfrac{b}{a} \\
x_1 x_2 + x_2 x_3 + x_3 x_1 = \dfrac{c}{a} \\
x_1 x_2 x_3 = -\dfrac{d}{a}
\end{cases}$$

## 5. بنك التمارين والمسائل التدريبية (مع الحلول المفصلة)

### 📌 التمرين الأول: تحليل كثير حدود بالقسمة الإقليدية وحل متراجحة
ليكن كثير الحدود $P(x)$ المعرف بـ:
$$P(x) = 2x^3 - 5x^2 - 4x + 3$$
1. تحقق أن $x_0 = -1$ جذر لـ $P(x)$.
2. أوجد كثير الحدود $Q(x)$ من الدرجة الثانية بحيث يكون: $P(x) = (x + 1) Q(x)$، باستعمال القسمة الإقليدية أو طريقة هورنر.
3. حل في $\mathbb{R}$ المعادلة: $P(x) = 0$.
4. ادرس إشارة $P(x)$ في جدول منظم، ثم استنتج حلول المتراجحة: $P(x) \ge 0$.

---

### 💡 الحل المفصل للتمرين الأول:
1. **التحقق من أن $x_0 = -1$ جذر لـ $P(x)$:**
   $$P(-1) = 2(-1)^3 - 5(-1)^2 - 4(-1) + 3 = 2(-1) - 5(1) + 4 + 3 = -2 - 5 + 4 + 3 = 0$$
   بما أن $P(-1) = 0$، فإن العدد $-1$ هو بالفعل جذر لـ $P(x)$، وبالتالي $P(x)$ يقبل القسمة على $(x - (-1)) = (x + 1)$.

2. **تعيين $Q(x)$ بواسطة القسمة الإقليدية:**
   نقسم $2x^3 - 5x^2 - 4x + 3$ على $x + 1$:
   * $2x^3 \div x = 2x^2$
   * نضرب ونطرح: $(2x^3 - 5x^2) - (2x^3 + 2x^2) = -7x^2$
   * نُنزل الحد التالي: $-7x^2 - 4x$
   * $-7x^2 \div x = -7x$
   * نضرب ونطرح: $(-7x^2 - 4x) - (-7x^2 - 7x) = 3x$
   * نُنزل الحد الأخير: $3x + 3$
   * $3x \div x = 3$
   * نضرب ونطرح: $(3x + 3) - (3x + 3) = 0$ والباقي معدوم.
   * **إذن:** $Q(x) = 2x^2 - 7x + 3$.
   * التحليل الكامل: $P(x) = (x + 1)(2x^2 - 7x + 3)$.

3. **حل المعادلة $P(x) = 0$ في $\mathbb{R}$:**
   $$P(x) = 0 \iff (x + 1) = 0 \quad \text{أو} \quad 2x^2 - 7x + 3 = 0$$
   * الحل الأول: $x_1 = -1$.
   * بالنسبة للمعادلة $2x^2 - 7x + 3 = 0$:
     * المميز: $\Delta = b^2 - 4ac = (-7)^2 - 4(2)(3) = 49 - 24 = 25 = 5^2 > 0$.
     * الجذران:
       $$x_2 = \dfrac{-b - \sqrt{\Delta}}{2a} = \dfrac{7 - 5}{4} = \dfrac{2}{4} = \dfrac{1}{2}$$
       $$x_3 = \dfrac{-b + \sqrt{\Delta}}{2a} = \dfrac{7 + 5}{4} = \dfrac{12}{4} = 3$$
   * **مجموعة الحلول:** $S = \left\{-1, \dfrac{1}{2}, 3\right\}$.

4. **دراسة إشارة $P(x)$ وحل المتراجحة $P(x) \ge 0$:**
   ننشئ جدول إشارة الجداء $(x + 1)(2x^2 - 7x + 3)$:

| $x$ | $-\infty$ | | $-1$ | | $1/2$ | | $3$ | | $+\infty$ |
| :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| **$x + 1$** | | $-$ | $0$ | $+$ | | $+$ | | $+$ | |
| **$2x^2 - 7x + 3$** | | $+$ | | $+$ | $0$ | $-$ | $0$ | $+$ | |
| **الجداء $P(x)$** | | **$-$** | **$0$** | **$+$** | **$0$** | **$-$** | **$0$** | **$+$** | |

   * نستنتج المجالات التي يكون فيها الجداء موجباً أو معدوماً:
   * **حلول المتراجحة $P(x) \ge 0$ هي:**
     $$S = \left[-1, \dfrac{1}{2}\right] \cup [3, +\infty[$$
