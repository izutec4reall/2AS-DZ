# 📚 سلسلة التمارين الشاملة: المتتاليات العددية

---

## 📝 الجزء الأول: نص التمارين

### 🟢 التمرين 1 (المتتاليات الحسابية)
$(u_n)$ متتالية حسابية حدها الأول $u_1$ وأساسها $r$ حيث:
$$\begin{cases} u_2 + u_5 = 26 \\ u_3 + u_7 = 36 \end{cases}$$
1. احسب الأساس $r$ والحد الأول $u_1$.
2. اكتب عبارة $u_n$ بدلالة $n$.
3. احسب المجموع: $S = u_1 + u_2 + \dots + u_{50}$.

---

### 🟡 التمرين 2 (المتتاليات الهندسية)
$(v_n)$ متتالية هندسية حدودها موجبة تماماً حدها الأول $v_0$ وأساسها $q$ حيث:
$$v_1 \times v_3 = 144 \quad \text{و} \quad v_0 + v_1 = 6$$
1. احسب الحد $v_2$ باستعمال الوسط الهندسي.
2. احسب الأساس $q$ والحد الأول $v_0$.
3. احسب المجموع: $S_n = v_0 + v_1 + \dots + v_n$ بدلالة $n$. ثم احسب نهايته لما $n \to +\infty$.

---

### 🔴 التمرين 3 (مسألة تراجعية شاملة مع متتالية مساعدة هندسية)
لتكن المتتالية $(u_n)$ المعرفة على $\mathbb{N}$ بـ: $u_0 = 2$ ومن أجل كل $n \in \mathbb{N}$:
$$u_{n+1} = \dfrac{1}{3}u_n + 4$$
1. احسب الحدود $u_1$ و $u_2$ و $u_3$. هل المتتالية $(u_n)$ حسابية أو هندسية؟
2. نعتبر المتتالية $(v_n)$ المعرفة على $\mathbb{N}$ بـ: $v_n = u_n - 6$.
   * أثبت أن $(v_n)$ متتالية هندسية أساسها $q = \dfrac{1}{3}$ وحدها الأول $v_0$.
   * اكتب عبارة $v_n$ بدلالة $n$، ثم استنتج عبارة $u_n$ بدلالة $n$.
   * احسب نهاية $(u_n)$ لما $n \to +\infty$.
3. احسب المجموعين التاليين بدلالة $n$:
   * $S_n = v_0 + v_1 + \dots + v_n$
   * $T_n = u_0 + u_1 + \dots + u_n$

## 💡 الجزء الثاني: الحلول المفصلة خطوة بخطوة

### حل التمرين 1:
1. **حساب الأساس والحد الأول:**
   * في المتتالية الحسابية: $u_n = u_1 + (n - 1)r$.
   * $u_2 = u_1 + r$، $u_5 = u_1 + 4r \implies u_2 + u_5 = 2u_1 + 5r = 26$.
   * $u_3 = u_1 + 2r$، $u_7 = u_1 + 6r \implies u_3 + u_7 = 2u_1 + 8r = 36$.
   * بطرح المعادلة الأولى من الثانية: $(2u_1 + 8r) - (2u_1 + 5r) = 36 - 26 \implies 3r = 10$?
     دعنا نحسب: $8r - 5r = 3r \implies 3r = 10 \implies r = 10/3$.
     أو بتعديل الأرقام: $3r = 10$.
     $2u_1 = 26 - 5(10/3) = 26 - 50/3 = 28/3 \implies u_1 = 14/3$.

2. **عبارة الحد العام:**
   $$u_n = \dfrac{14}{3} + (n - 1)\dfrac{10}{3} = \dfrac{10n + 4}{3}$$

3. **المجموع $S$:**
   * عدد الحدود 50:
     $$S = \dfrac{50}{2} (u_1 + u_{50})$$
     $$u_{50} = \dfrac{10(50) + 4}{3} = \dfrac{504}{3} = 168$$
     $$S = 25 \times \left(\dfrac{14}{3} + 168\right) = 25 \times \dfrac{518}{3} = \dfrac{12950}{3}$$

### حل التمرين 2:
1. **الوسط الهندسي:**
   $$v_1 \times v_3 = v_2^2 \implies v_2^2 = 144 \implies v_2 = 12 \quad (\text{لأن الحدود موجبة})$$

2. **حساب الأساس $q$ والحد الأول $v_0$:**
   * $v_1 = v_0 \cdot q$ و $v_2 = v_0 \cdot q^2 = 12 \implies v_0 = \dfrac{12}{q^2}$.
   * نعوض في $v_0 + v_1 = 6$:
     $$\dfrac{12}{q^2} + \dfrac{12}{q} = 6 \iff \dfrac{2}{q^2} + \dfrac{2}{q} = 1 \iff 2 + 2q = q^2 \iff q^2 - 2q - 2 = 0$$
     $\Delta = 4 + 8 = 12 \implies q = \dfrac{2 + \sqrt{12}}{2} = 1 + \sqrt{3}$.

---

### حل التمرين 3:
1. **حساب الحدود:**
   * $u_1 = \dfrac{1}{3}(2) + 4 = \dfrac{14}{3} \approx 4.67$.
   * $u_2 = \dfrac{1}{3}\left(\dfrac{14}{3}\right) + 4 = \dfrac{14}{9} + \dfrac{36}{9} = \dfrac{50}{9} \approx 5.56$.
   * $u_1 - u_0 = 14/3 - 2 = 8/3$. بينما $u_2 - u_1 = 50/9 - 42/9 = 8/9 \neq 8/3 \implies$ ليست حسابية.
   * $u_1 / u_0 = 7/3$. بينما $u_2 / u_1 = 25/21 \neq 7/3 \implies$ ليست هندسية.

2. **المتتالية المساعدة $(v_n)$:**
   * $v_{n+1} = u_{n+1} - 6 = \left(\dfrac{1}{3}u_n + 4\right) - 6 = \dfrac{1}{3}u_n - 2 = \dfrac{1}{3}(u_n - 6) = \dfrac{1}{3}v_n$.
   * إذن $(v_n)$ هندسية أساسها $\mathbf{q = \dfrac{1}{3}}$ وحدها الأول $v_0 = u_0 - 6 = 2 - 6 = \mathbf{-4}$.
   * $v_n = -4 \left(\dfrac{1}{3}\right)^n$.
   * $u_n = v_n + 6 = \mathbf{6 - 4 \left(\dfrac{1}{3}\right)^n}$.
   * النهاية: بما أن $|1/3| < 1$، فإن $\lim (1/3)^n = 0 \implies \mathbf{\lim_{n \to +\infty} u_n = 6}$.

3. **حساب المجاميع:**
   * مجموع المتتالية الهندسية:
     $$S_n = v_0 \dfrac{1 - q^{n+1}}{1 - q} = -4 \dfrac{1 - (1/3)^{n+1}}{1 - 1/3} = -4 \dfrac{1 - (1/3)^{n+1}}{2/3} = \mathbf{-6 \left[1 - \left(\dfrac{1}{3}\right)^{n+1}\right]}$$
   * مجموع $T_n$:
     بما أن $u_k = v_k + 6$:
     $$T_n = \sum_{k=0}^n (v_k + 6) = \sum_{k=0}^n v_k + \sum_{k=0}^n 6 = S_n + 6(n + 1)$$
     $$\mathbf{T_n = -6 \left[1 - \left(\dfrac{1}{3}\right)^{n+1}\right] + 6n + 6 = 6n + 6\left(\dfrac{1}{3}\right)^{n+1}}$$
